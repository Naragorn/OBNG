## Purpose

Returns an actor's base actor value as an integer: it calls 0x005EAD00 (float result in
ST0) with the actor value code it was given, narrows that to float (FSTP float at
0x005F191A, before any comparison, read), and returns floor((float)v) (towards minus
infinity) converted to int in EAX (derived from the instruction sequence
0x005F1915-0x005F195A, see Control flow and claim 6; it holds for any rounding of
0x009828C0 that returns an integer within 1 of its input, truncation included - that
rounding behaviour is pseudocode only, unverified at instruction level).

It is a leaf wrapper: it touches no field of any object itself, no Havok state, no clock.
All object access happens in 0x005EAD00.

## Control flow

Linear except one branch. Let `v` = 0x005EAD00(avCode) stored to float at 0x005F191A.

1. 0x005F1924: `t = ftol(v)` (EAX). 0x005F192D-0x005F1935: `tf = (float)t`.
2. 0x005F193B: `d = v - tf` (x87 precision, FSUBP ST2,ST0 leaves d under tf).
3. 0x005F193F-0x005F194A: FCOMP d with 0.0 (pops d), FNSTSW, `TEST AH,0x1` (C0),
   **JZ 0x005F1952** - branch at 0x005F194A:
   - **taken when C0 = 0**: d >= 0.0 (d not less than 0.0 and ordered) -> result base `tf`.
   - **falls through when C0 = 1**: d < 0.0, **or d is NaN** (unordered sets C0) ->
     0x005F194C `tf - 1.0`.
4. 0x005F1952: store to float, reload, 0x005F195A `ftol`, return in EAX, `RET 4`.

Test flows a rebuild needs (derived from the above; the finite in-range results hold for
any 0x009828C0 rounding that returns an integer within 1 of its input, see claim 6):
- positive integer v (3.0 -> 3), positive fraction (2.5 -> 2), zero (0.0 -> 0),
- negative integer (-2.0 -> -2, d = 0 -> branch taken), negative fraction (-2.5 -> -3),
- -0.0 (d = 0 -> taken, 0),
- NaN from 0x005EAD00 (falls through; result is whatever ftol gives for NaN - unverified),
- v beyond int range (EAX is the low dword of 0x009828C0's 64-bit result, `_ftol2` shape
  in pseudocode - unverified).
(A flow '|v| >= 2^24 with inexact (float)t' is unreachable: a float of that magnitude is
already an integer, so t = v and (float)t is exact - derived.)

Pseudocode vs instructions: pseudo.c shows `FUN_005ead00(param_1); FUN_009828c0();
FUN_009828c0(); return;` - it drops the x87 data flow, the comparison, the branch at
0x005F194A, the subtraction of 1.0 and the int return. The instructions win.

## Claims

1. read: three calls, 0x005F1915 -> 0x005EAD00, 0x005F1924 and 0x005F195A -> 0x009828C0.
2. read: one conditional branch, JZ at 0x005F194A on x87 C0 after comparing with [0x00A2FC68].
3. read: data.json gives [0x00A2FC68] = 0.0 (double) and [0x00A2F928] = 1.0 (double).
4. read: callee cleanup, RET 0x4 at 0x005F195F; one stack argument.
5. derived (from 1, and no ECX write before 0x005F1915): ECX is forwarded as `this` to
   0x005EAD00; the function is __thiscall.
6. derived (from 2, 3 and the x87 sequence 0x005F191A-0x005F195A): the result is
   floor((float)v) - the FSTP float at 0x005F191A narrows 0x005EAD00's ST0 result before
   any comparison. Valid when (float)v is finite and floor((float)v) fits int32, for any
   0x009828C0 rounding that returns an integer within 1 of its input (t = floor gives
   d >= 0 -> tf; t = ceil of a non-integer gives d < 0 -> tf - 1; the integer part is
   always exact, since |t| < 2^24 when v has a fraction and t = v otherwise). That rounding
   property of 0x009828C0 is pseudocode only (unverified). NaN and out-of-int32 results
   depend on 0x009828C0 (unverified; out of range, EAX is the low dword of `_ftol2`'s 64-bit
   result per pseudocode).
7. derived (from 2): when d is NaN the 1.0 is subtracted (C0 set on unordered).
8. read: no explicit memory write outside its own argument slot [ESP+4]; implicit stack
   writes are the PUSH EAX at 0x005F1914 and the return addresses of the CALLs at
   0x005F1915, 0x005F1924, 0x005F195A (outgoing slots below ESP). No write to any data
   outside its own frame; no global, heap, Havok or clock access in its own body.
9. read (meta.json): 0x00603CA0 (Actor::Update) is a direct caller; 0x00605770
   (Actor::UpdateHigh) is not.
10. measured (sampler run 20261114-151935): it is also reached from 0x00605770 through
