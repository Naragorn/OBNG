## Purpose

Fills four fields of a ray-cast collector object (`this`, built on the caller's stack), builds a
small 0x20-byte cast-input record on its own stack from the ray input (`arg2`), and calls
slot +0x38 of the object in `arg1` (by the caller: `[callerThis+0x64]`, read at 0x00898EEF; that it is
the world's broad phase is a proposal, unverified) with
(&record, this, 0). Before and after, it writes one record each into the thread's profiler stream
in the TLS block (+0x1A4 cursor, +0x1A8 end): start marker "TtRayCstCchSim" and end marker "Et",
each with the low 32 bits of RDTSC. It writes nothing on the world, the bodies, the broad phase,
the heap or Havok's stack area 0x00B47900 itself; whatever the broad phase's slot +0x38 and the
collector's callbacks write is outside this function (unfollowed).

5. Who sets TLS +0x1A4/+0x1A8 for a thread, and who drains the stream (the monitor-stream owner); a second thread without them simply records nothing (C15).
