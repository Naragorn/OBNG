## Purpose

The actor's per-update tick of its vital actor values (derived from the callees and the actor-value
codes listed below). In order:

1. A time step: `elapsed = now - this+0xBC`, with a reset when the stored stamp is ahead of `now`
   or negative (read, 0x005FAAE3..0x005FAB48). A NaN stamp takes neither reset branch (both
   compares at 0x005FAAFC and 0x005FAB07 are unordered and 0x005FAB05 / 0x005FAB12 treat that as
   'keep'), so elapsed = now - NaN = NaN, not 0 (derived from the read instructions and x87
   compare semantics).
2. Virtual +0x2E4(elapsed) (unfollowed).
3. Virtual +0x198(0); when it returns non-zero the rest is skipped (read, 0x005FAB6C).
4. Virtual +0x330(); when non-zero and (the player is not in chargen, or the player's +0x590 is
   <= 0): virtual +0x33C(elapsed) and 0x00420E90 on this+0x44 with this (read, 0x005FAB72..0x005FABB2).
5. The running fatigue drain: when the process's movement flags have 0x200 (running) and any of
   0x0F (moving), `cost = 0x00547F40(GetAV(0xB) / 0x00547ED0(GetAV_F(0))) x elapsed x
   setting[mastery(base AV 0xD)]` and `-cost` is passed to 0x005E07D0 when cost > 0 (read
   0x005FABB7..0x005FACBF). The linear form `x m + b` inside 0x00547F40 and the reading of the
   ratio as encumbrance / capacity come from callee pseudocode (0x00547F40, 0x00547ED0) and OBVR
   FatigueCost.h, not from this export (unverified; the instructions of 0x00547F40 and 0x00547ED0
   would settle it). Meaning of the flags from OBVR TeleportNoise.h, of the call from OBVR
   FatigueCost.h "0x005FACBF running ... fFatigueRunBase times the Athletics perk's share"
   (derived from OBVR).
6. The player-only bow burn: when this is the player, the process's +0x2D0 returns 5 and the
   mastery of actor value 0x1C is 0, fatigue is lowered by `[0x00B37010] x elapsed` through
   0x005E07D0 (read 0x005FACC8..0x005FAD16; OBVR FatigueCost.h names 0x005FAD16 "a bow held
   drawn ... fMarksmanFatigueBurnPerSecond").
7. 0x005F2720(elapsed) - fatigue regeneration (unverified, callee pseudocode only).
8. Magicka regeneration (actor value 9) via +0x2A4(9, amount, 0), unless the MagicCaster at
   this+0x5C answers non-zero from its +0x30 virtual, and only when max > floor(current) and
   amount > 0 (read 0x005FAD25..0x005FAE3B; the amount test is 0x005FAE1C..0x005FAE25, whose JNZ
   skips the call when amount <= 0 or unordered and pops ST0 at 0x005FAE3D).
9. 0x005E7A60(elapsed) - counts down the timers of the list at this+0x9C and removes the expired
   entries (unverified, callee pseudocode only).
10. When the player's byte +0x594 is non-zero: 0x005F2530(elapsed) - health regeneration
    (unverified, callee pseudocode only).
11. Virtual +0x2D8(elapsed) (unfollowed).
12. `this+0xBC = now` on every path, also the early exit of step 3 (read, 0x005FAE7F..0x005FAE83).

## Calling convention and parameters

- `__thiscall`: ECX = this (an Actor), copied to ESI at 0x005FAAEA (read).
- One stack argument, a float `now` at [ESP+4] on entry (read 0x005FAAE3 `FLD [ESP+0x10]` after
  `SUB ESP,0xC`; 0x005FAE7F `FLD [ESP+0x14]` after `PUSH ESI`).
- Callee cleans: `RET 0x4` at 0x005FAE8D (read). No return value (the FPU stack is empty at
  the RET, derived from the instruction stream; EAX holds whatever the last callee left).
- The caller passes the return of 0x00673B00 with ECX = 0x00B3BD00 (read, 0x00605B6E); 0x00673B00
  returns the float at 0x00B3BCF0 and 0x00673B10 is what stores it (unverified, rea-all pseudocode
  only). The caller's own prologue runs the same stamp idiom on this+0xBC (read,
  0x006057A6..0x00605831).

Stack frame (ESP after `PUSH ESI` = S): S+4 scratch (cost / magicka max), S+8 `elapsed`,
S+0xC scratch (capacity, ratio, current magicka), S+0x14 `now` (read from the offsets used).

## Claims

1. 0x005FAAE0 is `__thiscall` with one float stack argument and `RET 4`. (read, 0x005FAAEA, 0x005FAE8D)
2. It is reached through actor vtable slot 0x368 from 0x00605770 at 0x00605B7F, with the value of 0x00673B00 as argument. (read, caller asm.s)
3. this+0xBC holds a time stamp: on every path that reaches the RET it is set to the argument. (read, 0x005FAE7F..0x005FAE83; all paths join there)
4. For finite values: when stamp <= now and stamp >= 0, elapsed = now - stamp; when stamp > now or stamp < 0, elapsed = 0, except 0 < now < 0.3 where elapsed = now and the reset writes stamp = 0.0 at 0x005FAB3A before the final overwrite at 0x005FAE83. When stamp is NaN, both compares (0x005FAAFC, 0x005FAB07) are unordered, 0x005FAB05 / 0x005FAB12 take the normal path (B2 'or unordered'), and elapsed = now - NaN = NaN, not 0. (read, 0x005FAAE3..0x005FAB48; 0.3 from data.json; the NaN case derived from the read compares and x87 unordered semantics)
5. When vtable +0x198(0) returns non-zero, nothing but the stamp write runs. (read, 0x005FAB6C)
6. When the process flags have 0x200 and any of 0x0F, cost = 0x00547F40(AV(0xB) / 0x00547ED0(AV_F(0))) x elapsed x setting[mastery(base AV 0xD)], and -cost is passed to 0x005E07D0 when cost > 0. (read for the data flow 0x005FABB7..0x005FACBF; flag meanings derived from OBVR TeleportNoise.h) The linear form `x m + b` and the encumbrance / capacity meaning come from callee pseudocode (0x00547F40, 0x00547ED0) and OBVR FatigueCost.h (unverified; the instructions of those two callees would settle it).
7. The process pointer at this+0x58 is dereferenced at 0x005FABBA before its null test at 0x005FABD1; a null process faults there. (read)
8. The player-only fatigue burn runs when process+0x2D0() == 5 and the mastery of base value 0x1C is 0, cost [0x00B37010] x elapsed. (read 0x005FACC8..0x005FAD16; "bow held drawn" from OBVR FatigueCost.h)
9. Magicka (9) regenerates by 0x00548D60(willpower-ish AV 2, AV 0x39, max) x elapsed through +0x2A4(9, amount, 0) when max = base + modifier > floor(current) and amount > 0, unless MagicCaster+0x30() != 0.
