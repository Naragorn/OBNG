## Purpose

The constructor of the loading-screen menu. In order:

1. Runs the base constructor 0x00584640 on `this`, writes the vtable
   0x00A6C40C and initialises the menu's fields (0x005AD116-0x005AD141).
2. If `(*g_osGlobals 0x00B33398)->+0x24` is nonzero, calls 0x006A9B40 on it
   (0x005AD145-0x005AD158).
3. Reads the four loading-bar section shares through the pointer table
   0x00B14120 (`LoadingMenu::pSectionPercentage`, name from the string at
   0x00A6C3B8), copies each into the float array 0x00B3B3DC, sums them as
   float, and zeroes `this+0x2C..+0x38` (0x005AD15D-0x005AD1AD). A missing
   entry produces the "Missing" warning.
4. If `|1 - sum|` is not below 0.01f (or the sum is NaN), composes a
   multi-line warning into a 0x400-byte buffer and passes it to 0x004A7A60
   (0x005AD1AF-0x005AD2E4).
5. Allocates the menu's private `TimeInfo` (0x18 bytes), initialises it with
   `GetTickCount()` through `TimeInfo::Init` 0x0047D150, stores it at
   `this+0x54`, runs `TimeInfo::Update` 0x0047D170 on it with a second
   `GetTickCount()`, copies its `clockMs` (+0x10) into `this+0x68` and
   `this+0x6C`, loads the float setting 0x00B14158 into `this+0x40`, and
   returns `this` (0x005AD2E7-0x005AD366).

### Where pseudo.c and asm.s disagree (the instructions win)

- pseudo.c passes the GS cookie copy (`uVar5`) to `FUN_00584640`; the
  instructions pass only ECX = this (0x005AD116). The `PUSH EAX` at 0x005AD102
  is the EH frame's cookie slot, not an argument.
- pseudo.c declares `void` and `__fastcall`; the function returns `this` in
  EAX (0x005AD341), and EDX is never read as a parameter.
- pseudo.c drops ECX of `FUN_006a9b40` (0x005AD14A), the 0x18 of
  `FormHeap_Allocate`, the tick arguments and ECX of `Init`/`Update`, the
  index argument of the "Missing" warning (0x005AD17B), and the name argument
  of the NOT FOUND line (0x005AD22E) - which hides the NULL read of C7.
- pseudo.c compares `(float)_DAT_00a3b150 <= fVar4`; that is false for NaN,
  while the instructions emit the warning on NaN (B5). The float cast is
