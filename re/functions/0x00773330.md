## Purpose

For each of five sampler-state slots i = 0..4, the function pushes one
sampler state to the render-state object held in the global 0x00B42834:
when the byte [this+0xA4+i] is nonzero it sends the value [this+0x90+4i],
otherwise when the byte [this+0x80+i] is nonzero it sends [this+0x6C+4i],
otherwise nothing; the call is `slot+0xD0(stage, kTypes[i], value, 0)` with
`kTypes` the dword table at 0x00B427CC and `stage` the function's only
argument. It returns 0. (Mechanism **read**, 0x00773340-0x007733A4.)

That slot +0xD0 is a cached SetSamplerState, that the five types are
D3DSAMP_ADDRESSU / ADDRESSV / MAGFILTER / MINFILTER / MIPFILTER and that
`this` is a texture-stage state group are **unverified**; they rest on
pseudocode of 0x007802D0, 0x0077B610, 0x00773100 and 0x007721E0 (Claims
C9-C14). No vertex stream, no packer, no buffer lock or unlock, no clock.

## Calling convention and parameters

- `__thiscall`: ECX is read before any write (`MOV EBP,ECX` at 0x00773337)
  and used as the base of every field access (**read**).
- One stack argument: `MOV EBX,[ESP+0x8]` at 0x00773331 after one
  `PUSH EBX` (0x00773330), i.e. [ESP+4] at entry (**read**). It is passed
  unchanged as the first argument of every slot +0xD0 call (0x00773366,
  0x00773390; **read**). Its meaning (the texture stage index) is
  **unverified**: 0x00773440 compares it with the global 0x00B28CB0 before
  calling the sibling, and 0x00772400 passes `[this+0]` of its own object
  (pseudocode of both, rea-all).
- Callee cleans: `RET 0x4` at 0x007733A4 (**read**).
- Preserves EBX, EBP, ESI, EDI (pushed at 0x00773330/35/36/39, popped at
  0x0077339E-0x007733A3; **read**).
- Returns EAX = 0 unconditionally (`XOR EAX,EAX` at 0x007733A1; **read**).
  The return values of the slot calls are discarded (**read**: EAX is not
  read after 0x00773367 / 0x00773391 before being overwritten).
- The indirect callee is called thiscall-shaped: ECX = [0x00B42834]
  (0x0077334D, 0x00773377), four pushes in the order 0, value, kTypes[i],
  stage, so the callee sees `(stage, kTypes[i], value, 0)`; no stack
  adjustment follows the call (0x00773369, 0x00773393), so the callee pops
  its 16 bytes (**derived** from the pushes and the balanced POPs at
  0x0077339E ff.).

## Control flow

Every branch becomes a test flow of a rebuild.

| # | At | Condition | Effect |
|---|---|---|---|
| F1 | 0x00773340 / JZ 0x00773348 | byte [this+0xA4+i] == 0 | go to F2; else call slot +0xD0 with value [this+0x90+4i] (0x0077334A-0x00773367), then JMP 0x00773393 (0x00773369) |
| F2 | 0x0077336B / JZ 0x00773373 | byte [this+0x80+i] == 0 | skip to the loop step 0x00773393; else call slot +0xD0 with value [this+0x6C+4i] (0x00773375-0x00773391) |
| F3 | 0x00773399 / JL 0x0077339C | ESI (i+1) < 5, signed | loop back to 0x00773340; else epilogue, return 0 |

No other branch: no null test of [0x00B42834] or of the vtable, no early
exit, exactly five iterations (**read**: ESI starts at 0, 0x0077333A, and
only `ADD ESI,1` 0x00773393 changes it).

Flows for a rebuild (each i independently): (B set) -> call with B value;
(B clear, A set) -> call with A value; (both clear) -> no call; (both set)
-> B value only. Plus: all five clear -> no call and no read of
[0x00B42834] at all (**derived** from F1/F2: 0x00B42834 is loaded only
inside the call blocks); any flag set while [0x00B42834] is 0 -> access
violation at 0x00773353 or 0x0077337D (**derived**, no null test).

## Claims

  `RET 4`, returns 0 in every path.
- **C2** (read): the function makes no memory store other than its own
  pushes; it writes no field of `this` and no global.
- **C3** (read): it reads no clock and no timer global; the only globals
  read are 0x00B42834 and the table 0x00B427CC.

## Open questions

- Q1: The render-state class's vtable: is +0xD0 0x0077B610 and +0xC8
  0x0077B140, and does its RTTI locator name `NiDX9RenderState` (xOBSE RTTI
  0x00B2A838)? Cheapest step: read the vtable whose entries include
  0x0077B610 in .rdata (one Ghidra/REA data read).
- Q2: Instruction-level confirmation of the table values (0x007802D0) and of
  0x0077B610's cache and device call (C9, C10).
- Q3: Who calls 0x00772400 (vtable owner) and how often per draw / pass: is
  it NiD3DTextureStage's apply per stage per pass (Gamebryo naming,
  unverified)? This decides whether redundant sampler sets reach D3D9 at all
  - 0x0077B610 already skips unchanged values (C10), so the lever is likely
  small.
- Q4: The meaning of group A (+0x6C/+0x80) versus group B (+0x90/+0xA4) and
  of the +0xB0 bytes (saved state versus per-pass override; a "use map
  value" flag?) - needs 0x00773100's callers.
- Q5: Why the group-A return 0x00773393 never appears in the samples (C16):
  group A unused in this scene, or only shorter-lived (unverified).
- Q6: The inclusive table of OBVR's `tools/perf-functions.py` counts stale
  return words (C18). A filter that keeps a return word only when the word
  above it is a return address into a function that calls the first one
  would remove this class of artefact; it belongs to OBVR (not edited from
  here).
