## Purpose

When the cull walk reaches the ShadowSceneNode, this function runs the node's part of
the eye pass in place of NiNode's plain child walk. In order (every step read in asm.s,
addresses in Control flow):

1. **Light maintenance** (only when byte this+0x12C is 0): walks the node's light list
   (head this+0xE8 of the list at +0xE4, knowledge/shadow-light-list-remove.md). Per
   ShadowSceneLight: a light whose source NiLight (light+0x100) is gone or held only by
   the light (refcount 1) is removed (0x007C77C0); otherwise the moved-light rescan
   0x007C6020 runs when light+0x104 is set, and the per-light update 0x007D6390(process)
   runs unless the light is a shadow caster (light+0xF4) while shadows are on
   (0x00405A80). Then the list is re-sorted, 0x007C71B0(camera).
2. **Globals for the pass**: the node index byte this+0x11C into 0x00B42F30, the camera
   into the refcounted global 0x00B43124.
3. **Fallback path** ([0x00B42F48] == 0): a fresh 0x38-byte NiAlphaAccumulator
   (C10) replaces the renderer's accumulator, begin(camera), the NiNode child walk
   0x0070AB40(process), finish, restore. No constants, no fog. Return.
4. **Shader path** ([0x00B42F48] != 0):
   - a save/override/restore of the dword 0x00B42F40 through 0x00B2D18C, decided by the
     byte 0x00B42E86;
   - three vec4 entries of the constant table 0x00B46498 through 0x007ECAE0: 0x1C the
     camera's world translate, 0x1D and 0x1E two columns of its world rotation, w = 0;
   - the fog vec4s 0x00B46638 / 0x00B46648 from the node's fog property (type 1), when
     the node has one;
   - 0x00B460B8 = lerp of 0x00B46064 and 0x00B46068 by 0x00B2C670;
   - the BSShaderAccumulator singleton (0x007B7650) replaces the renderer's accumulator
     [renderer+0x08]; begin(camera); acc+0x21E0 = 1; the NiNode child walk
     0x0070AB40(process), which registers the visible geometry; acc+0x21E1 = 1;
     finish 0x007AE070 (the draw, 4.98 ms a frame over its two calls per
     knowledge/culling-and-draw-setup.md "Round two", not re-measured here, C22); the old accumulator is put back.

It reads no frame-clock global (C20).

  0x007C7A64, 0x007C7D31): the `NiCullingProcess*` (C3).
- Callee cleans: `RET 0x4` at 0x007C7DB4.
- No return value: EAX is not set on the way to 0x007C7DA1 (NiAVObject's slot +0x7C
  is void; derived from the instructions, the Gamebryo signature not checked).

  cookie (`[0x00B30AAC] XOR ESP` pushed at 0x007C78EC); the cookie is popped at
  0x007C7DAC without a check on the normal exit; the handler bytes in data.json

  list node (loop) and later the saved renderer accumulator (0x007C7D06); +0x1C the

## State left for the next pass

What a single pass that culls once and draws twice would have to keep or reset (all
derived from the claims above):

- **Accumulator** (0x007B7650's object): +0x08 = the camera of the last begin, +0x21E0 =
  1 and +0x21E1 = 1 (C11; who clears them is unverified), +0x2268 cleared by the finish
  (0x007AC9A0.md C3), the pass lists retired by RenderPassList except on its batch path
  (0x007AC9A0.md C9). A second finish without a begin and a walk finds +0x2268 = 0 and
  draws nothing (0x007AC9A0.md C3) - so drawing the same lists twice needs either a
  change inside the finish or the lists kept and +0x2268 set again (unverified which).
- **Renderer accumulator** [renderer+0x08]: restored to the caller's value.
- **Globals**: 0x00B43124 the last camera; constant entries 0x1C..0x1E the last eye's
  camera; entries 0x1A/0x1B the fog of the last node with fog; 0x00B460B8; 0x00B42F30;
  0x00B42F40/0x00B2D18C override state (C16).
- **Lights**: removed lights stay removed, the sort order stays, per-light state from
  0x007D6390 (fade, culled flag +0x118 per knowledge) is whatever the last eye's planes
  gave - in OBVR's dual pass the per-light update runs twice a frame, the second time
  with the second eye's planes (derived from C5/C6).
