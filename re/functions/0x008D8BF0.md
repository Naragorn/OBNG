## Purpose

Drains the pending-operation queue that hangs at `[world+0x80]` (R 0x00899262-0x00899268: 0x00899210
loads `ECX = [world+0x80]` and calls here). It swaps the queue's record array out for an empty
16-record buffer on its own stack, raises `[world+0x98]`, executes each taken record (0x14 bytes, the
type byte at +0) through a 34-way jump table, releases the record's Havok reference(s) and frees its
heap blocks, and after each record recurses into itself when that record queued new operations.
At the end it gives the original array back (count 0), lowers `[world+0x98]`, and frees the
temporary array if it had grown onto the heap (R, sections below). It takes no lock and reads no
clock (R: no import call and no RDTSC in asm.s; the profile markers live in 0x00899210).

## Calling convention and parameters

- `__thiscall`, `this` (the queue object) in ECX, copied to EBX (R 0x008D8BFD) and to `[ESP+0x14]`
  (R 0x008D8C05). No stack parameters: plain `RET` (R 0x008D8E18), so `ret 0`; pseudo.c's
  `__fastcall(int *param_1)` is the same shape.
- Frame: `AND ESP,0xFFFFFFF0` (16-byte aligned), `SUB ESP,0x1B4` (R 0x008D8BF3/0x008D8BF6).
- Returns nothing (EAX not set on the exit path for a caller; R 0x008D8E12-0x008D8E18).
- Callees' conventions as the call sites show them: thiscall unless noted; 0x008CC570 cdecl 2 args
  (R `ADD ESP,8` 0x008D90D8), 0x008CD320 cdecl 3 args (R `ADD ESP,0xC` 0x008D8FD0), 0x008A9D10
  cdecl 1 arg (R `ADD ESP,4` 0x008D9192).
