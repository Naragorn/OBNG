## Purpose

Fills the GPU buffers of one skin partition: it writes the partition's draw counts into
the partition's buffer-data record, re-packs the vertex streams through the shader
declaration (or a fixed-function fallback) when the geometry's dirty bits ask for it,
and re-fills the 16-bit index buffer when the index bits ask for it. It returns AL = 1
when the record is usable, AL = 0 on a null input or a failed pack.

The order inside one call (read):
1. gates: null record or geometry -> 0 (0x0076313F, 0x0076314B);
2. `0x00777F10` on the record: are all stream slots allocated (0x00763153);
3. early-out with 1 when not forced, allocated and the geometry is static
   (`[geom+0x2E] & 0xF000 == 0x4000`, 0x00763167-0x0076317C);
4. the vertex-format key into `record+0x00` (0x0076317F-0x007631A9);
5. counts from the partition: vertices, triangles, strips, index count (0x007631AC-0x00763201);
6. stream count from the declaration (`decl+0x20`) or 1 without one (0x00763203-0x0076321C);
7. the dirty mask: the geometry's low 12 bits, or 0xFFF when the geometry is volatile
   (0x8000) or forced (0x00763220-0x00763241);
8. stream slots: reallocate through `0x00777F70` when not allocated or when the count
   changed, which also forces dirty = 0xFFF (0x00763246-0x00763295);
9. the record's counts and the partition's index pointers (0x0076329A-0x007632C6);
10. per stream i: `decl->vt[0x6C](geom, skin, partition, dirty, chip_i, i, 0)`, or with a
    single stream the fallback `0x007774C0` on `[this+0x8B0]` (0x007632C9-0x00763345);
11. when dirty has 0x10 or 0x20: `0x007781F0` on `[this+0x8B4]` (the index buffer
    manager, by its strings - unverified) packs the triangle list, and a new index
    buffer replaces the old one through `0x00777F40` (0x00763347-0x007633AE).

Where it sits in a scene pass (derived from the exe scans): the per-draw caller
0x0077A310 is vtable slot 15 (+0x3C) of 32 shader vtables - NiD3DShader,
NiD3DDefaultShader and 30 Oblivion shaders (ShadowLightShader, SkinShader, HairShader,
SpeedTree*, Water*, ParticleShader, ...; class names from the RTTI COLs). It calls this
function only when `[shader+0x34] == 0`, or when `[shader+0x34] != 0` and the geometry is
volatile (0x8000) and the partition is non-null (objdump 0x0077A31D-0x0077A33D);
otherwise it binds the record passed as its own arg 4 without packing (0x0077A37A). It
then binds the record's streams and index buffer on the device (C22). The other caller 0x00769030 is a batch flush that runs after the
renderer's `vt+0xB0` call (pseudocode, unverified) and forces a full pack.

## Calling convention and parameters

`__thiscall`, six stack arguments, the callee cleans: `RET 0x18` at all four exits
(read). ECX is saved to a frame slot at 0x0076313B and read back as `[ESP+0x20]` at
0x0076331C and as `[ESP+0x38]` (after six pushes) at 0x00763373 (read). Both call sites
push six arguments (objdump: 0x007692A4-0x007692B7 and 0x0077A34D-0x0077A35E).

The return value is a bool in AL only. AL is set with `MOV AL,1` (0x00763176, 0x007633B4)
or `XOR AL,AL` (0x0076338C, 0x007633BE); the upper 24 bits of EAX are whatever the last
operation left (read). pseudo.c types the return as `undefined4`; the instructions say
AL (instructions win).

## Claims

C1. **read** - Six stack arguments, callee cleans: `RET 0x18` at 0x0076317C, 0x00763392,
0x007633BA, 0x007633C4. `this` arrives in ECX (saved at 0x0076313B).

C2. **read** - The return value is AL: 1 at 0x00763176 and 0x007633B4, 0 at 0x0076338C
and 0x007633BE. pseudo.c's `undefined4` return is wider than the instructions set.

C3. **read** - Null record (0x0076313F) or null geometry (0x0076314B) returns AL=0 before
anything is called or written.

C4. **read** - Early-out: when `force` is 0 (0x00763158), 0x00777F10 returned non-zero
(0x00763163) and `geom[+0x2E] & 0xF000 == 0x4000` (0x00763167-0x00763173), the function
returns AL=1 at 0x0076317C without writing the record.

C5. **read** (objdump 0x00777F10-0x00777F3F) - 0x00777F10 returns AL=0 when
`record[+0x1C] == 0` or when any `record[+0x24][i]` or its `+0x08` is null, else AL=1.
**derived**: the early-out can only fire for a record whose every stream already has a
buffer.

C6. **read** - `record[+0x00]` is overwritten with
`((geom[+0x2C] & 0x3F) << 24) | (geom[+0x20] ? 0x00800000 : 0) | (geom[+0x24] ? 0x00400000 : 0)`
(0x0076317F-0x007631A9). The 0x00400000 is the immediate at 0x00763194 (data.json lists it
as the DOS header only because Ghidra took it for an address).

C7. **read** - Index count: `3 * partition[+0x1E]` with one group when
`partition[+0x22] == 0`, else `partition[+0x1E] + 2 * partition[+0x22]` with
`partition[+0x22]` groups (0x007631CA-0x007631FD). **derived**: `+0x1E` counts triangles
and `+0x22` strips (a strip set of n triangles in s strips has n + 2s indices).

C8. **read** - Stream count: `decl[+0x20]` when `decl` is non-null, else 1
(0x00763203-0x0076321C).

C9. **read** - The dirty mask is 0xFFF when the geometry's consistency nibble is 0x8000
(0x00763232-0x00763241) or `force` is non-zero (0x0076323A); otherwise it is
`geom[+0x2E] & 0xFFF` (0x0076322C). **derived** (C9, C12, C20): for volatile geometry the
geometry's own dirty bits are ignored; every stream pack is called with dirty 0xFFF and
0x007781F0 is called (dirty has 0x30). That the callees then copy every element and every
index is **unverified** (0x0076FE20 / 0x007781F0 pseudocode only). A failed stream pack
with streamCount != 1 returns at 0x00763312 before the index refill (C18).

C10. **read** - Stream slots: when 0x00777F10 said "not allocated", the function calls
`[[record+0x04]]+0x1C(record, i)` for i = 0 .. streamCount-1 (0x00763265-0x00763278), then
`0x00777F70(streamCount)` on the record (0x00763281) and zeroes `record[+0x34]`
(0x00763286). When allocated but `streamCount != record[+0x1C]`, only `0x00777F70` runs
(0x00763255). Both paths force dirty = 0xFFF (0x00763295).
**unverified** (pseudocode of 0x00777F70, `RET 4` read by objdump at 0x0077803A):
0x00777F70 reallocates the two per-stream arrays at `+0x20` and `+0x24` to the new count,
keeps the old entries, zero-fills new ones, calls `[[record+4]]+0x1C` for dropped ones
and sets `record[+0x1C]`.

C11. **read** - Record counts are written on every call that passes B5:
`+0x14 = +0x18 = partition[+0x1C]`, `+0x3C = +0x40 = partition[+0x1E]`,
`+0x44 = strips or 1`, `+0x48 = partition[+0x18]`, `+0x4C = partition[+0x14]`
(0x0076329A-0x007632C6). `+0x38` is not written here.

C12. **read** - Streams are packed only when dirty has a bit other than 0x10
(`TEST EAX,0xFFFFFFEF` at 0x007632BB, branch 0x007632C9) and streamCount is non-zero.

C13. **read** - Per stream i with a declaration: `decl->vt[+0x6C]` is called with ECX =

seven arguments, matching the seven pushes in C13. It calls the copier 0x0076F590 at
0x0077006D, the chip allocation 0x00776C40 (0x0076FF4D), the lock wrapper 0x00776C90
(0x0076FF83), 0x0072AF20 (0x007700B9) and the unlock 0x00776D80 (0x007700D0).
**derived** (C13, C14, C15): **the copier 0x0076F590, and through it the routine table
filled at 0x00771356 and the stream copy 0x0076E610, enter this packing through the
declaration's vtable slot +0x6C = 0x0076FE20**, not through any direct callee of
0x00763130.

C16. **unverified** (pseudocode of 0x0076FE20) - 0x0076FE20 locks stream i's chip
(when given no locked pointer), walks the declaration's elements (0x1C bytes each,
count at decl `+0x1C`), calls 0x0076F590 for each element whose dirty bit is set
(positions bit 1, normals and tangent-like elements bit 2, colors bit 4, texture sets bit
8), and unlocks with 0x00776D80. It calls 0x0072AF20 only when `skin != 0` and
`partition == 0`. **derived** from this plus C17 (partition is never null here): on the
path from 0x00763130 the 0x0072AF20 branch is not taken.

C17. **read** - `partition` is dereferenced at 0x007631B0 without a null test, so a
caller must pass a non-null partition (derived). Both call sites guarantee it: 0x0077A33F
tests the partition and routes the null case to 0x00767B40 instead (objdump), and
0x00769030 does the same on its list entry's `+0x08` (objdump 0x0076929F-0x007692A6).

C18. **read** - Fallback: when `decl` is null, or its slot +0x6C returned 0, and
streamCount is 1 (0x0076330D-0x00763312), `0x007774C0` is called on ECX =
`[this+0x8B0]` with `(geometry, skin, partition, dirty, chip_i, 0)`
(0x00763314-0x0076332D); EAX = 0 returns AL=0 (0x00763334). With streamCount != 1 a failed
slot call returns AL=0 at once (0x00763312), leaving the record's counts already
rewritten (C11) and the index buffer not packed.

C19. **read** (objdump) - 0x007774C0 returns with `RET 0x18` (0x00777A3A) and returns a
value in EAX: `XOR EAX,EAX` at 0x0077761F on a failed chip allocation or a negative
Unlock result (0x00777A18), else `[ESP+0x20]` (0x00777A1E). Its Ghidra signature
(`void`) is wrong there; the instructions win. Its call list has no 0x0076F590 and no
0x00776D80: it packs with its own loops and inlines the staging copy (memcpy 0x009812C0
at 0x007779E8, then the buffer's vtable +0x30 at 0x00777A14) (objdump; the meaning of
the memcpy arguments is from pseudocode, **unverified**).

C20. **read** - Index buffer: when dirty has bit 0x10 or 0x20 (0x00763347),
`0x007781F0` is called on ECX = `[this+0x8B4]` with
`(partition.triangleList, indexCount, indexCount, record[+0x30], &size, 1, usage)`,
where `size` starts as `record[+0x2C]` and `usage` is 0x10 when `record[+0x10] != 0`, else
0 (0x0076334C-0x0076337E). `RET 0x1C` of 0x007781F0 (objdump 0x00778201 and three more)
matches the seven pushes.
**unverified** (pseudocode of 0x007781F0): it reuses the old buffer when its description
matches (format 0x65, the same usage and pool, enough bytes), otherwise creates one through
the device's vtable +0x6C (CreateIndexBuffer, by its error string), then locks and copies
`2 * indexCount` bytes. D3D meanings (0x65 = D3DFMT_INDEX16, pool 1 = D3DPOOL_MANAGED,
0x10 = D3DUSAGE_SOFTWAREPROCESSING) are recalled, not checked in this run.

C21. **read** - After the index pack: a zero result returns AL=0 (0x00763387); the same
buffer as before returns AL=1 without touching `+0x28`, `+0x2C`, `+0x30` (0x00763397);
a different buffer first releases the old one through 0x00777F40 (0x0076339B), then stores
the new buffer, `indexCount` and the size (0x007633A0-0x007633AE).
**derived**: when the old buffer is reused, `record[+0x28]` keeps its previous value even
if the index count changed.

C22. **read** (objdump 0x0077A310-0x0077A3E0) - The per-draw caller 0x0077A310 is a
thiscall with four stack arguments (`RET 0x10` at 0x0077A3E0). Arg 1 is an object whose
`+0xB4` is the geometry data and `+0xB8` the skin; arg 2 is the partition; arg 3 is the
record returned unchanged when nothing is packed. When `[this+0x34] != 0`, it packs only
if the data's consistency is 0x8000 and the partition is non-null
(0x0077A31D-0x0077A33D); when `[this+0x34] == 0`, it always packs. Partition non-null:
`0x00763130(record = partition[+0x28], data, skin, partition, decl = [this+0x24], 0)`
with ECX = `[this+0x14]` (0x0077A34D-0x0077A35F); partition null: 0x00767B40 with
`(data[+0x38], data, skin, decl, 0)` (0x0077A366-0x0077A373). The return value of
either call becomes the record (0x0077A37E), whose streams are then bound one by one
through the device's vtable +0x190 with `(i, chip[+0x08], 0, record[+0x20][i])` and whose
`+0x30` goes to vtable +0x1A0 (0x0077A390-0x0077A3D9). D3D method names for +0x190 /
+0x1A0 (SetStreamSource, SetIndices) are recalled, **unverified**.

C23. **read** (exe scan) - 0x0077A310 is slot +0x3C (slot 15) of 32 vtables in
`.rdata`, named by their COLs: NiD3DDefaultShader, NiD3DShader, MapShader, BlurShader,
MenuBGShader, SkyShader, HDRShader, ShadowLightShader, WaterShader,
WaterShaderDisplacement, WaterShaderHeightMap, ParticleShader, TallGrassShader,
BlurShader_P20, GethitShader, PrecipitationShader, SpeedTreeLeafShader, BoltShader,
NighteyeShader, DebugShader, Lighting30Shader, RefractionShader, BSShader,
BSImageSpaceShader, CopyShader, GeometryDecalShader, ParallaxShader, SkinShader,
HairShader, SpeedTreeFrondShader, SpeedTreeBranchShader, DistantLODShader.
Ghidra has no function at 0x0077A310 (no `0x77a310.c` in rea-all; the preceding body
0x0077A1F0 ends at 0x0077A304).

C24. **read** (objdump) - 0x00769030's call at 0x007692BA pushes `force = 1` (0x007692A4)
and takes `record = entry[+0x18]`, `geometry = entry[+0x00]`, `skin = entry[+0x04]`,
`partition = entry[+0x08]`, `decl = entry[+0x0C]` from a list entry, ECX = EBP.
0x00769030 is itself called at 0x004C5819, 0x005511C7 (jmp), 0x00562FFF and 0x0076BE12
(exe scan); at 0x005511C0 and 0x00562FF9 ECX is loaded from `[0x00B3F928]` right before.
**unverified** (pseudocode of 0x00769030): it walks a list filled by the renderer's
`vt+0xB0` call that precedes it at those sites, and afterwards clears the dirty bits of
static data (keeps `& 0xF000`).

C25. **derived** (C4, C9, C18, C22) - Which geometries are packed again in a scene pass:
from the per-draw caller, force is 0, so a skinned partition with static data and all
streams allocated returns at the early-out. For volatile data (0x8000), 0x00763130 calls
every stream pack with dirty 0xFFF and calls 0x007781F0 on every call it gets from
0x0077A310 with a non-null partition (0x00763241, 0x007632BB, 0x00763347); 0x0077A310
itself calls 0x00763130 only under the conditions in C22. That the callees then copy all
elements and all indices is **unverified** (0x0076FE20 / 0x007781F0 pseudocode only). A
failed stream pack with streamCount != 1 returns at 0x00763312 before the index refill.
Mutable data (any other nibble) is packed per its own dirty bits. That skinned bodies carry the 0x8000 nibble is **unverified** (it would
explain OBVR's measured repacking every pass; a log of `geom[+0x2E]` at 0x00763130 in
the game would settle it).

C26. **derived** (C9, C10, C11, C20, C21) - What is per geometry and what already persists
across passes. Persistent in the record: the stream count and per-stream chips
(`+0x1C/+0x20/+0x24`), the index buffer and its size (`+0x2C/+0x30`), `+0x28` (indexCount:
written only at 0x007633AB after a replacement, so kept when the buffer is reused,
0x00763397), `+0x34` (zeroed only on the not-allocated path 0x00763286, not on a count
change), and `+0x04` and `+0x10` (never written here). Re-done on every call that passes
the early-out: the format key, the counts and index pointers (constant work), and - for
volatile or forced data - a call to every stream pack with dirty 0xFFF and a call to
0x007781F0. That 0x007781F0 copies `2 * indexCount` bytes each time is **unverified**
(its pseudocode, C20); nothing in this function tests whether the triangle list changed.

C27. **unverified** (hypothesis; rests on C25, C26 and OBVR numbers from
knowledge/skinned-vertex-streams.md, **measured** there, not here) - Why OBVR's
StreamReuse found no gain. **read/derived** part: this function's own work per call is
constant plus one virtual call per stream; the bytes are moved inside 0x0076FE20 /
0x0076F590 / 0x0076E610 (or 0x007774C0) and 0x007781F0 (C15, C19, C20). Skipping the
copies alone would still leave the chain 0x0077A310 -> 0x00763130 -> 0x0076FE20
lock/unlock plus the index lock and copy. The hypothesis: IF OBVR's skip sits at or below
the copier, the lock, unlock and index refill remain, and the work left over would then
be of the order of the ~0.14 ms OBVR measured - that figure only agrees with this
reading, it does not follow from it. knowledge/skinned-vertex-streams.md line 152 says
92 % of the packs were skipped, so the hook level decides. OBVR's StreamReuse source
(`src/render/StreamReuse*`) and its hook point were not read in this run; reading them
would settle it.

C28. **read** - No clock: the body has no absolute memory operand, so it neither reads
nor writes a TimeInfo or frame-clock global. The callees are not covered.

C29. **derived** (C14, C15, C23) - **For OBVR**: knowledge/skinned-vertex-streams.md says
"0x00771790 and 0x00773330 call the packer 0x0076FE20". The exe scan finds no E8/E9 call
or jump to 0x0076FE20 anywhere in `.text` and its only pointer is the
NiDX9ShaderDeclaration vtable slot; every route into it is a virtual call through slot
+0x6C. 0x00763130 is one of those routes (0x00763307). Whether 0x00771790 and 0x00773330
make such a virtual call was not checked (**unverified**); their pseudocode shows no
`+0x6c` call (0x00773330 only has a `+0x6c` field address).

## Callees worth their own slice

| Address | Why |
|---|---|
| 0x0076FE20 (NiDX9ShaderDeclaration vtable +0x6C) | the per-stream packer: lock, per-element copier calls, unlock - the bridge to 0x0076F590 and the routine table |
| 0x0077A310 (shader vtable +0x3C, no Ghidra function yet) | the per-draw "prepare geometry" step: the only per-pass caller of this function; binds streams and indices |
| 0x007781F0 | the index buffer pack: create/reuse plus a full refill per call |
| 0x007774C0 | the fixed-function fallback packer with inline staging copy and the "ILLEGAL WEIGHTS" check |
| 0x00777F70 | the stream-array resize with per-slot release |
| 0x00767B40 | the non-partition sibling (same caller pattern, `record = data[+0x38]`) |
