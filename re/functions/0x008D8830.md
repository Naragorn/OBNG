## Purpose

Appends one 0x14-byte operation record to a world's pending-operation array under the queue's
critical section, counts it in `[world+0x84]`, and makes the record self-contained: it takes a
reference on every object the record points to and, for the types that carry an out-of-line
payload (an object-pointer array, or a 0x20-byte box for type 0x11), copies that payload into a
fresh heap block owned by the record. The drainer 0x008D8BF0 later runs each record, drops the
references and frees the heap blocks (pseudo.c of 0x008D8BF0; U at instruction level).

Clock: this function's own body contains no RDTSC and no clock global (R, asm.s, whole body).
The lock-enter callee 0x008A7720 (enter is D, see Callees) executing RDTSC only when
TryEnterCriticalSection fails and the thread's TLS block has `+0x1B4 != 0` (profiling markers
"TtCriticalLock" into TLS +0x1A4..+0x1A8) is U: the only source is the rea-all pseudocode
`re/export/rea-all/functions/0x8a7720.c`, not instructions. 0x008A7720's asm would settle it.

profiling with RDTSC per pseudocode only, U), 0x008A6EE0 + 0x008A7560/0x008A75D0 (array growth on
the thread memory), the `[0x00BA7D98]` allocator (vt+0x10 allocate, vt+0x14 free).

## Layout requests

- `WorldOperationQueue` (proposal): `+0x00 Record* data`, `+0x04 int32 size`,
  `+0x08 uint32 capacityAndFlags` (mask 0x3FFFFFFF; bit 31 = storage not owned, U),
  `+0x0C uint32 world` (handle), `+0x10 CRITICAL_SECTION lock` (0x18 bytes, U). Its place in the
  world (`world+0x80`) is U.
- `WorldOperationRecord` (proposal): size 0x14; `+0x00 uint8 type`, `+0x04 uint32 a` (handle) or
  array pointer, `+0x08 uint32 b` / box pointer / `uint16 count`, rest per type.
- `hkWorld` (proposal): `+0x84 int32 pendingCount`.
- Referenced object header (proposal): `+0x04 uint16 memSizeAndFlags`, `+0x06 int16 referenceCount`.
- Box payload: 0x20 bytes, two 16-byte halves (AABB min/max, U).
