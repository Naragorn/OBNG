## Purpose

Once per world render (called from 0x0040C830), this function:

1. Runs a small enable/disable state machine for actor shadows on the
   bit 0x10 of the dword at 0x00B42F40 and the bytes 0x00B333B8 /
   0x00B333F6, and re-reserves shadow maps through 0x007C2710 when the
   state flips (0x004073D3-0x0040746D).
2. Calls 0x007B7650 unconditionally (0x00407472).
3. When shadows are on, picks up to `count` casters (count = the dword at
   0x00B06F04 or 0x00B06EFC by `[g_TES]+0x34`): the player first under its
   own checks, then the data of each node of the list 0x006747C0 returns
   for 0x00B3BD00, and registers each one's node with the shadow scene
   object returned by 0x007B4280(0) through 0x007C6C30 (0x004074A7-0x00407684).
4. Hides the first-person node, the node `[[g_TES]+0x5C]+4`, the object at
   `[0x00B36094]` (unless the byte 0x00B06F14 is set) and two TES-managed
   node groups (0x00442A30 with 0 and 3), sets the culling process's +0x0C to
   the scene camera, then walks the shadow scene's lights (0x007C5AB0 /
   0x007C5B50) and draws at most `count` of them (0x00407752-0x004079C9).
5. Restores what it hid, brackets 0x007C6770 with 0x00977C50(3) /
   0x00977C50(2), and sets the byte 0x00B0727C back to 1
   (0x004079CF-0x00407A6C).
6. On every path (including all early exits), runs the canopy shadow timer
   `Sky::0x00543A00(fSetting(0x00B06530) * frameSeconds)` when the byte
   0x00B430AD is set and a menu-mode condition allows it (0x00407A72-0x00407ACB).

## Claims

   and returns with a plain `RET` (0x004073DA, 0x00407AD7; see Calling
   convention).

   `[[g_TES]+0x34] != 0`, else the dword at 0x00B06EFC (0x004074CB-0x004074DB);
   image values 4 and 2 (data.json). The Int/Ext names are OBVR's

   0x00A3EC20, not the strings).

   to the canopy timer without walking any caster or light
