## Purpose

Run once per actor before ApplyAnimData 0x00471F20, and only when the anim
data's dirty word `[this+0x00]` and both nodes `[this+0x04]`, `[this+0x08]` are
non-null. It decides whether the actor's skeleton is animated this frame:

- **Animated path** (0x00471CDB): taken directly by a non-player with
  `actor+0xB0 == 1` (0x00471C65) or `actor->vt+0x334(1)` true (0x00471C77).
  Otherwise (and always for the player, who skips those two tests at
  0x00471C59) the fade test runs first: if the actor's vt+0x154 node is a
  BSFadeNode with fade <= 0 (ordered), the actor - the player included -
  takes the hidden path (0x00471CAE). Past the fade test the player goes to
  the animated path (0x00471CB9) and a non-player only if its root bound
  passes the camera frustum test 0x0047F7B0 (0x00471CD5). The animated path
  sets mask 0x1 of `actor+0xC4`, sets/clears mask 0x2 by a lookup on the
  singleton 0x007B7650 keyed by `actor+0x0C`, sets/clears mask 0x4 by the
  BSFadeNode fade value against 1e-5, optionally
  detaches one object (a light, by form type 0x1A; U) around the controller
  run, writes 1 to the global byte 0x00B3CBD0 when A != 0, and runs the root node's
  NiMultiTargetTransformControllers through 0x0047CA30 with the time
  `[this+0x94]` and `[this+0x08]`. The output for ApplyAnimData is the bones'
  controller-written transforms (D: 0x0047CA30 -> 0x0047C740 not followed, U
  what exactly it writes).
- **Hidden path** (0x00471E58): clears mask 0x1 of `actor+0xC4` and, instead of
  animating, writes a synthetic world bound into the root node
  `[this+0x04]+0x20..+0x2C`: centre = actor position (vt+0x174) with
  z + 0.25 * d, radius = max(old radius, d), where d = 2 * the float the base
  form gives through 0x0046D5C0.

Both working paths end with `[this+0x00] = 0` (R 0x00471E40, 0x00471EFA), i.e.
the dirty word is consumed.

## Calling convention and parameters

- `__thiscall`: ECX = the anim data (`MOV EBX,ECX` 0x00471C27) (R). In
  Actor::Update the ECX is EBX, the value of `actor->vt+0x164()` stored at
  0x00603D1E, the same EBX that is passed to ApplyAnimData at 0x006043DC (R).
- One stack argument at `[ESP+0x44]` after the prologue: the actor
  (`PUSH EBP` at 0x00604254, EBP = actor) (R). It is compared with
  g_thePlayer 0x00B333C4 (R 0x00471C4A). The slot is reused as a bool
  (0x00471C55), as a float scratch (0x00471D35, 0x00471EB4) and as a local
  NiPointer (0x00471D77..0x00471E4E) (R).
- Callee cleans: `RET 0x4` (R 0x00471F13). Returns nothing used (EAX is
  whatever the last path left; U whether any caller reads it - 0x00603CA0
  does not test EAX after 0x0060425C, R).
- SEH frame (handler 0x009AEC58, state at `[ESP+0x3C]`, set to 0 at
  0x00471D7D and -1 at 0x00471E46 around the local NiPointer) and an EH cookie
  `[0x00B30AAC] ^ ESP` pushed at 0x00471C1C, popped unchecked at 0x00471F0B (R).

2. R - nothing is done unless `[this]`, `[this+4]`, `[this+8]` are all non-null (0x00471C29-0x00471C40).
3. 4.
