## Purpose

Draws one geometry (a NiTriStrips when reached from 0x00719BA0, unverified C2) with the
pipeline the caller left on the device: no shader pass loop, no SetupTransformations,
no buffer packing. In instruction order:

1. return at once when renderer byte +0x6F0 is set (0x0076970D);
2. return when the data's virtual +0x50 returns zero in AX (0x0076972C; for
   NiTriStripsData that is the vertex count, 0x007693E0.md C6);
3. load the geometry's world bound +0x20..+0x2C into EBX and three stack slots
   (0x0076973B-0x00769747);
4. `usePartitions = 0x00768890(geometry, 0)` (thiscall on the renderer, 0x0076975B);
5. load `record = [data+0x38]` (0x0076976C), cast geometry+0xBC to NiD3DShaderInterface
   through 0x00560920 (0x00769779), call the cast result's slot 18 (+0x48) unchecked
   (0x0076978E);
6. store the bound loaded in step 3 into renderer +0x658..+0x664 (0x0076979C-0x007697B4);
7. call `[[renderer+0x8AC]+0xFF0]` slot 1 (+0x04) (0x007697C5);
8. draw: skinned arm (per partition, bone gate, DrawIndexedPrimitive per array entry) when
   usePartitions is set, else the whole arm (DrawPrimitive when record+0x30 is zero, else
   DrawIndexedPrimitive per array entry);
9. `data+0x2E &= 0xF000` on every path past step 2 (0x007698A3 / 0x00769914 / 0x00769946).

It is slot 90 (0x007694F0) plus steps 3 and 6 (C11).

  vtable slot 34 (+0x88) the direct render entry `(renderer)`: 0x007176D0 for NiTriShape
  (-> renderer slot 90), 0x00719BA0 for NiTriStrips (-> renderer slot 91).
