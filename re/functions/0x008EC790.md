## Purpose

Moves a point (output +0x00) along a velocity (output +0x10) through a set of
moving planes (input +0x48, count input +0x4C, 0x40 bytes each), for at most
the time input +0x40:

1. Copies input position and velocity to the output and clears one 0x10-byte
   status record per plane in output +0x24.
2. Loop: finds the earliest plane the point reaches before the remaining time
   runs out (skipping planes already active and planes whose status +0x0C is
   non-zero), moves the point to it when that time exceeds 1e-4, adds the
   plane to a stack-resident active set of four 0x0C-byte slots and calls
   0x008EC340, which projects the velocity onto the active planes and, when
   the append made the count 4, reduces it to 3 again (see Claim 8).
3. Stops when no plane is hit (output +0x20 = input +0x40), when the time used
   exceeds input +0x44, or when the remaining time becomes negative.

Subsystems touched, in order: the caller's input record (read), the caller's
output record and its status array (write), the stack-resident active set,
then 0x008EC340 (projection; its own file re/functions/0x008EC340.md). This
body itself touches no world, no broad phase, no phantom, writes no global,
uses no thread-local slot, no heap, no Havok stack area 0x00B47900 and no
clock (read, Claim 1). The same is not settled for the call tree: the five
callees of 0x008EC340 are not followed (Claims 3, 5, 6).

## Control flow

Every branch, with the instruction that decides it. x87 flags after FCOMP:
C0 = less, C3 = equal, C0+C2+C3 = unordered (NaN).

| # | Address | Condition | Taken | Not taken |
|---|---|---|---|---|
| 1 | 0x008EC7D0 | count (input +0x4C) <= 0 (`JLE`) | skip status clearing | clear status[i] for i < count, re-reading count each pass (0x008EC7FE) |
| 2 | 0x008EC80F | remaining time < 0.0 or NaN (`TEST AH,1`, `JNZ`) | return at once; output +0x20 not written | enter the loop with active count 0 |
| 3 | 0x008EC836 | count <= 0 | no plane scan, hit = -1 | scan planes |
| 4 | 0x008EC845/0x008EC84B | active count >= 1 and active[0].index == i | skip plane | next test |
| 5 | 0x008EC854/0x008EC85A | active count >= 2 and active[1].index == i | skip plane | next test |
| 6 | 0x008EC863/0x008EC869 | active count >= 3 and active[2].index == i | skip plane | next test |
| 7 | 0x008EC877 | status[i] +0x0C != 0 | skip plane | compute speed |
| 8 | 0x008EC8CC | speed `-((out.vel - plane.vel) . plane.n)` <= 0.0 (`TEST AH,0x41`, `JNP`) | skip plane | continue (also for NaN) |
| 9 | 0x008EC936 | distance `plane . (out.pos - totalTime * plane.vel)` > FLT_EPSILON or NaN (`JP`) | keep distance | distance := 0.0 |
| 10 | 0x008EC960 | distance + status[i] +0x08 >= speed * tMin, or unordered (`TEST AH,5`, `JP`) | no update | tMin := (distance + extra) / speed, hit := i |
| 11 | 0x008EC986 | i < count (re-read) | next plane | leave scan |
| 12 | 0x008EC99F | tMin <= 1e-4 or NaN (`TEST AH,0x41`, `JNZ`) | no advance, go to 15 | advance |
| 13 | 0x008EC9E0 | active count <= 0 (flags of `TEST EBX,EBX` 0x008EC9A1, kept across x87/SSE) | skip status update | for each active plane: status +0x04 += tMin, status +0x00 = 1 (loop 0x008ECA03) |

| 15 | 0x008ECA1C | hit < 0 | output +0x20 = input +0x40, return | add plane `hit` to the active set, status +0x08 := (status +0x08 + FLT_EPSILON) * 2, call 0x008EC340 |
| 16 | 0x008ECA6D | remaining time >= 0.0 (`TEST AH,1`, `JZ`) | loop again (0x008EC817, active count reloaded) | return (also for NaN); output +0x20 keeps its last value |

Arithmetic order the rebuild must keep (read):
- speed dot: `z + (y + x)` in SSE single (0x008EC8A7-0x008EC8AF), then x87 FCHS.
- distance: `(y + x) + (z + w)` with plane w added unscaled (0x008EC902-0x008EC91C); the swept point is `out.pos + (-totalTime) * plane.vel` over all four lanes.
- advance: `out.pos += tMin * out.vel` over all four lanes (ADDPS 0x008EC9D6), so out.pos.w changes when out.vel.w != 0.
- tMin, distance, time used and remaining time are x87 values stored to single floats.
