## Purpose

Given a small set of active constraint planes (one to four) held in a solver-state block on the caller's stack, it
computes the velocity that satisfies all of them and drops planes until the set is consistent. It is a state machine
on the active-plane count at state+0x30: with one plane it projects the input velocity onto it; with two it tries
plane 1 alone, else solves both; with three it tries the third alone, then pairs, else all three; with four it sorts,
tries every triple, and, when none holds, removes the plane whose interaction record has the largest +0x0C value.
The result velocity goes to output+0x10. It is pure geometry over the caller's own data: no global, no world, no
heap, no clock in its own instructions (read, see Claims).
