# The OCCLUSION probe over four kinds of place: which share of the geometries an
# eye's world pass draws lies wholly behind other geometry (plugin/src/
# OcclusionProbeLogic.h has the measure). The game runs its own code in the
# dual pass ([Route] StereoDraw=0, so OBVR draws each eye in its own pass);
# OBNG.dll samples one eye pass in 31. At each place the head is turned
# through eight directions for 2.5 s apiece:
#   market   coc ICMarketDistrict01      the Imperial City's Market District (a walled city worldspace)
#   plaza    coc ICTalosPlazaDistrict01  the Imperial City's Talos Plaza District (a walled city worldspace)
#   dungeon  coc ImperialDungeon01       the Imperial Prison's first dungeon level (an interior of corridors)
#   house    coc WeynonPrioryHouse       Weynon Priory's house (a small interior)
#   road     cow Tamriel -27 -3          the Gold Road midway between Kvatch and Skingrad (open country)
# The cell names are CELL records' editor ids read in Oblivion.esm
# ("coc ICMarketDistrict", the worldspace's id, leaves the player where he is:
# run 20261105-085711). Where the player stood is in OBVR.log ("Camera: at the
# mark - the eyes at"); the harness's pictures of a headless run are black.
# The probe's lines carry the performance counter ("qpc"), the marks carry the
# same clock ("tick"), so tools/occlusion-summary.py sums the lines between a
# place's mark and its "-done" mark.
#
# Run, from OBNG's folder (OBNG.dll deployed):
#   tools/shadow-run.sh --ini tools/hand-scripts/obng-measure-occlusion.ini tools/hand-scripts/obng-occlusion.txt --save OBVRHarnessMOO --run-timeout 480
# then: python3 tools/occlusion-summary.py artifacts/shadow/obng-occlusion/<run>
