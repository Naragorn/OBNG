# The PACK CACHE probe on the fixed scene: the game runs its own code
# (nothing routed, nothing shadowed) and OBNG.dll hashes every packed vertex
# stream at its unlock 0x00776D80 and compares it with the last pack of the
# same (geometry, partition, chip) - the share of packs a cross-frame cache
# would skip (docs/subsystems/stream-packing.md, lever L3), plus the data's
# consistency nibble at the packer's entry. The body is the measurement
# pair's (obng-walkers-{original,routed}.txt, the save OBVRHarnessWalkers);
# only the OBNG-test.ini differs (tools/hand-scripts/obng-measure-packing.ini:
# [Probe] PackCache=1). The hashing costs frame time; this run measures the
# share, not the pass.
#
# Run, from OBNG's folder (OBNG.dll deployed, the save made):
#   tools/shadow-run.sh --ini tools/hand-scripts/obng-measure-packing.ini tools/hand-scripts/obng-walkers-packing.txt --save OBVRHarnessWalkers
# In OBNG.log look for the "Probe: pack cache - ..." lines.
