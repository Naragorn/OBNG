# obng-profile-prison-tutorial.txt's place (the copy of the Windows session's autosave in the Imperial Prison, save
# OBNGPrisonTutorial) for comparing pictures between two settings: AI off and the game's time stopped at the first
# mark, then both eyes dumped for two frames looking ahead, 45 degrees left and 45 degrees right. No capture.
# Run with the Windows mod list, once per setting:
#   python3 tools/run-with-windows-mods.py -- tools/shadow-run.sh --ini <ini> \
#     tools/hand-scripts/obng-prison-tutorial-eyedump.txt --save OBNGPrisonTutorial --run-timeout 300 --no-steamvr
ini Render SinglePassStereo=1
ini SelfCheck ShowPanel=0
ini Render GameResolutionWidth=4036
ini Render GameResolutionHeight=3376
expect Single-pass stereo: OBNG took the eyes ok (0)
ini Hands Enabled=1
ini Hands ReachOpens=0
ini Debug EyeDump=1
ini Debug EyeDumpFrames=2
console-at ready SetNumericINISetting "fAutoVanityModeDelay:Camera" 100000
console-at ready tai
console-at ready set timescale to 0
console-at settle CloseAllMenus
expect HandScript: finished
reject HandScript: WARNING

wait 12
mark ready
wait 8
mark settle
wait 6
head yaw 0
wait 2
mark ahead
wait 3
head yaw -45
wait 2
mark left
wait 3
head yaw 45
wait 2
mark right
wait 3
mark done
