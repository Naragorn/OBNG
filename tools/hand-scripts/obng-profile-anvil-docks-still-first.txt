# obng-profile-anvil-docks.txt with the order changed: forty seconds standing still FIRST, then the eight head
# turns, then forty seconds still again - to tell what the arrival costs from what the head's turning costs.
# Anvil's docks with the Windows mod list (Better Cities, Unique Landscapes), standing in front of
# The Flowing Bowl, at the Dream Air's frame size (an eye of 4036x3376). The spot is where the
# tavern's door puts the player outside: the interior door 000308EA of AnvilTheFlowingBowl
# (000308D2) teleports to the exterior door 0000BCB9 at -193234 -32705 245, heading -142 degrees
# (read from Oblivion.esm, the REFR's XTEL; Better Cities Full.esp does not touch that cell).
# The head goes through eight directions for three seconds apiece, then the player stands still
# for forty seconds looking where the door let them out. Noon, the weather fixed (00038EEE), the
# time stopped, so that runs compare.
# Run with the Windows mod list for the run:
#   python3 tools/run-with-windows-mods.py -- tools/shadow-run.sh \
#     --ini tools/hand-scripts/obng-measure-docks-all.ini \
#     tools/hand-scripts/obng-profile-anvil-docks.txt --save OBVRHarnessMOO --run-timeout 480
