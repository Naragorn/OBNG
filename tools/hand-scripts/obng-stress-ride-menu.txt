# The stress flight to Anvil (obng-stress-ride.txt) from the main menu, without a save and without the new game's
# clicks: `cow` typed on the main menu takes the game's default player into the world (measured 2026-11-13,
# obng-stress-ride-newgame/20261113-181553: every click missed, the menu stayed up, the console line loaded the
# cell and the flight ran). So the run depends on no save made under another plugin list - the start for the cut
# "Oblivion.esm alone" (tools/with-plugin-list.py) and for its control runs.
# Run: OBNG_STRESS_SCRIPT=obng-stress-ride-menu.txt OBNG_STRESS_SAVE=continue \
#      OBNG_STRESS_MODS=only:Oblivion.esm OBNG_STRESS_WITHOUT_DLL=OblivionWalkers.dll tools/stress-ride.sh <ini> <runs>
start main-menu

ini SelfCheck ShowPanel=0
ini Render GameResolutionWidth=4036
ini Render GameResolutionHeight=3376
ini Hands Enabled=1
ini Hands ReachOpens=0
ini Hands BodyCollision=1
ini Hands PhysicsRate=0
ini Performance Enabled=1
ini Performance GpuTiming=1
ini Performance StartAfterSeconds=60
ini Performance CaptureSeconds=130
ini Performance MaxRecords=262144
ini Performance Sampler=1
console-at ready cow Tamriel -33 -4
console-at ready set gamehour to 12
console-at ready SetNumericINISetting "fAutoVanityModeDelay:Camera" 100000
console-at placed CloseAllMenus
console-at placed player.setangle z 258
console-at placed tcl
console-at placed tgm
console-at placed player.setav speed 200
console-at turn-1 player.setangle z 78
expect Single-pass stereo: OBNG took the eyes ok (0)
expect HandScript: finished

reject CRASH:
